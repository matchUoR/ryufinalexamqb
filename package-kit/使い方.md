# 問題パッケージ作成キット

このキットは他のAIへ渡して、新しい問題PDFと教室回答PDFからパッケージを作成するためのものです。原本PDFや既存の個人学習履歴は含みません。

1. このキットZIP、問題PDF、教室回答PDFを他のAIに添付します。
2. 「AI作成プロンプト.md」の利用者指定欄を記入して依頼します。疑義照会回答があれば併せて添付します。
3. AIが作成した完成ZIPを管理ページで読み込み、検証結果・試験・冊子・作成者・版・件数を確認して取り込みます。
4. 問題・画像・正答の対応を確認して使用します。不明箇所は保留のまま保存できます。

## ファイル

- template/metadata.json：パッケージ名、作成者、表示版、出典資料。
- template/catalog/index.json：このパッケージに含む冊子の一覧。
- template/catalog/common.json：診療科、疾患、画像、出典等の共通情報。
- template/catalog/booklets/99-I-本試-A.json：1問の記入例。99期は実試験ではありません。
- build_package.py：標準Python 3でファイルサイズ・SHA256・ID・日時を計算し、完成ZIPを作成する補助プログラム。
- AI作成プロンプト.md：PDFからの転記・照合・分類・根拠確認・出力の依頼文。
- 記録基準.json：診療科・出題意図等の分類ルール。

完成ZIPと作成キットZIPは別です。作成キットをそのまま学習用パッケージとして読み込まないでください。「問題パッケージ記入例.zip」は形式確認専用で、実問題は含みません。

## メタ情報

作成者は表示名です。署名による本人証明ではありません。端末名を使う場合、書き出したパッケージの受取人にもその名前が見えます。共有前に必要に応じて変更してください。

created_atは初回作成日時、updated_atは更新日時、いずれもUTCのISO8601形式です。試験実施日とは別です。package_versionは1.0.0等の表示版です。更新の判定は冊子release_idと直前版参照・SHA256で行い、表示版だけで上書きしません。

既存問題を更新する場合は問題IDを維持し、元パッケージまたは管理ページの編集機能を使用してください。初版テンプレートから作り直すと別の問題として扱われます。学習履歴は問題パッケージに含めません。

## 画像・連問

画像はassets内に実ファイルとして格納し、JSONには相対パスとSHA256を登録します。画像があるが未収録、画像なし、原本未確認を区別します。共通症例や共通画像はserial_groups/asset_bindingsで紐付けます。記入例は構造を最小限にするため画像・連問を含みません。追加時はプロンプトの規則に従ってください。

## 限界

補助プログラムによるZIP作成は医学的な正しさや原本一致を保証しません。管理ページの検証と原本との照合を別途行います。AIが調べていない文献を出典にしたり、未確認の解答を公式解答として登録したりしないよう確認してください。
